# Sweet Crumbs Bakery

**Practice project, not a real bakery.** This site is a demo built by a web
development intern; no orders are processed.

## What this is

A one-page menu for a fictional bakery in Mithi, Sindh. It lists six products
with prices, opening hours, and a WhatsApp order link. Built with plain HTML
and CSS — no frameworks.

## What I learned

`loading="lazy"` tells the browser to wait until an image is near the screen
before downloading it, so a visitor does not download all six photos before
seeing anything.

## Run it locally

Open `index.html` in a browser. There is no build step and no server yet.
